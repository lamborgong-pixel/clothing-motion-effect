# Knit Rail

原生 HTML、CSS、JavaScript 服饰挂杆交互，打开本地 HTTP 服务即可运行：

```sh
python3 -m http.server 8000
```

访问 http://127.0.0.1:8000/。

维护衣服只改 `clothes.config.js`：商品信息、图片路径、可选挂点参数均在同一条目内。新增透明正侧面素材可以只填路径，边界和挂点自动测量；删除条目减少衣服，`enabled: false` 暂时隐藏，数组顺序就是挂杆顺序。详细示例和 iframe 接入方式见 [INTEGRATION.md](INTEGRATION.md)。

当前共 9 件单品，包括用户图片中的奶油色连帽卫衣。卫衣原图保存在 `assets/references/cream-hoodie-original.png`，正面与侧面挂衣素材分别是 `assets/cream-hoodie.png`、`assets/side/cream-hoodie.png`，由内置 imagegen 按用户原图生成；提示词见 `assets/hoodie-generation-prompts.md`。卫衣未提供价格，商品卡显示“价格待定”。

- 静止使用独立生成的真实侧面服饰素材，悬停后衣架和衣服转向正面。
- 页面首次加载且素材准备好后，9 件服饰以 75ms 的间隔从杆上方轻轻落位，每件落位约 560ms；挂钩在杆上停住，衣架与衣服带交错方向的惯性晃动并自然衰减。悬停和打开商品卡不会重播入场动画；提前点击色点可直接进入交互，减少动态效果模式则直接显示服饰。
- 挂钩朝向固定，仅沿杆移动；WebGL 深度缓冲遮住杆后挂钩，几何半径保证挂钩绕在圆柱外侧。
- 悬停单品通常保持原悬挂位置；杆端空间不足时在杆内微调。左右衣服按可见边缘留白，并减小组内间距。
- 点击打开商品卡，支持左右按钮、键盘方向键和手机滑动切换商品，首尾循环；支持关闭、Escape，并分别记住各件商品的尺码选择。
- 正侧素材保持等比缩放；通过 CSS 裁去正面图片原有挂钩，接到独立的金属挂钩层。
- 支持移动布局与减少动态效果偏好。挂杆材质使用原生 WebGL，无第三方框架、CDN 或构建依赖。

`clothes.config.js` 是单品配置的唯一来源；`catalog.js` 解析配置并读取图片尺寸与透明边界；`app.js` 管理单品和指针交互；`motion.js` 管理保留速度的解析弹簧、惯性摆动和按可见边缘计算的间距；`hardware.js` 管理金属杆与挂钩；`styles.css` 管理图片旋转及商品卡。

素材由内置 imagegen 生成，正面及挂杆原素材提示词在 `assets/generation-prompts.md`；新侧面提示词在 `assets/side/generation-prompts.md`。
早期生成的金属杆参考图保存在 `assets/references/chrome-rail-original.png`，实际运行使用 `hardware.js` 绘制的三维挂杆。
正侧图片是两张独立的摄影素材，旋转过程采用正交图片平面融合，不是完整服饰三维模型。

配置与图片测量的回归检查：`node tests/catalog.test.cjs`。仓库保留代码、运行图片、配置、接入示例、测试、生成提示词和参考素材；本地预览截图、录像、系统文件和缓存由 `.gitignore` 排除。

动画以时间而不是帧数计算：展开约 0.3–0.4 秒，滑动约 0.35–0.5 秒，转向带轻微回弹，前后摆动与侧摆随惯性衰减；两侧服饰随收拢向外倾斜约 2.2–3.25°。目标改变时保留位置和速度，鼠标穿过单品之间的空隙时保留当前布局。商品卡使用进入、退出过渡，并尊重减少动态效果设置。

Focus 两侧按图片不透明区域的边缘留白，而非按图片整张画布宽度：桌面 310px 高服饰两侧静止净空为 23.25px，其他尺寸随服饰高度调整；倾斜产生的额外宽度也计入杆端与两侧间距，相邻侧面按自身宽度压紧，杆端不足时整体压缩组内间距。
